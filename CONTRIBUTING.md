# Contributing to FreshLane

Thanks for your interest. FreshLane is a neighborhood supermarket digital storefront starter (Next.js + TypeScript + Tailwind).

## Maintainer

- **Owner / maintainer:** [Santhi Prakash](https://github.com/santhiprakash) (`@santhiprakash`)
- **Repository:** https://github.com/santhiprakash/freshlane

## Development setup

```bash
git clone https://github.com/santhiprakash/freshlane.git
cd freshlane
npm install
npm run dev
```

Open http://localhost:3000. No API keys are required for the MVP (mock data).

## How to contribute

1. Open an issue first for larger changes (features, architecture).
2. Fork the repo and create a branch from `main`.
3. Keep changes focused — one concern per PR.
4. Run `npm run lint` before opening a PR.
5. Update `PROGRESS.md` when behaviour or architecture changes.

## Commit style

Use Conventional Commits prefixes: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore` — e.g. `feat: add category filter chips`.
